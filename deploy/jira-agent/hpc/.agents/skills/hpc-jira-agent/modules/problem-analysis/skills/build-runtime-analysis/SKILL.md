# 构建与运行启用分析

适用于应用尚未进入正常计算的失败。保留原命令、首次有效错误及其上下文；构建末尾的汇总失败和退出码不是根因。

## 区分失败层

| 层次 | 需要核对的证据 | 后续选择 |
|---|---|---|
| 配置/依赖发现 | 实际配置命令、选项、依赖位置、生成日志 | 缺依赖还是错误发现路径；不默认升级整个环境 |
| 编译 | 首个失败源文件、完整编译命令、头文件/工具链身份 | 语法/API、架构、选项、资源耗尽或编译器自身异常 |
| 链接 | 完整链接行、缺失/重复符号、真实库与 ABI | 查明提供者和版本，不以任意软链接掩盖不兼容 |
| 加载/启动 | 可执行产物、实际加载路径、初始化错误、设备可见性 | 库闭包、插件/配置或设备初始化，不等同于编译失败 |

先用原方式复现，再在独立构建目录做最小变更；固定源码身份，区别清理本任务构建缓存与修改共享环境。不要同时升级 SDK、改源码并换编译选项后声称已定位。

MACA 兼容性问题按需读 [maca-porting-checkup](../../../application-analysis/skills/maca-porting-checkup/SKILL.md)，已有 HPC 构建方法用 [hpc-opt-skill](../../../application-analysis/skills/hpc-opt-skill/SKILL.md)。源码/镜像获取由 [远端实验](../../../remote-experiment/SKILL.md) 提供。

编译器自身崩溃转 [crash-analysis](../crash-analysis/SKILL.md)；编译成功但输出不对转 [correctness-analysis](../correctness-analysis/SKILL.md)；确认版本变化影响结果后再叠加 [回退对照](../regression-analysis/SKILL.md)。从未支持的新接口不自动判成回退。

## 交付与限制

给出失败层、复现命令、实际源码/依赖身份、区分实验和归因强度。编译通过只证明构建恢复；声称可用还需运行原案例并校验结果。若只获诊断授权，交付建议，不自动提交适配补丁或安装系统依赖。
