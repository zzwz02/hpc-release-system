# MetaX 官方文档查询

任务涉及环境准备、依赖安装或工具使用，而工单材料和当前环境不能提供足够信息时，查询 [MetaX 帮助站](https://help.hub.metax-tech.com/)。网页内容可能更新，Skill 只记录查询方法，不保存具体安装命令、仓库地址、版本或密钥。

## 查询方法

1. 明确当前需要确认的信息，并采集相关错误、工具或软件包名称、操作系统版本和 CPU 架构。
2. 在帮助站中按关键词搜索。无法使用网页搜索时，读取 `https://help.hub.metax-tech.com/search/search_index.json`，在 `title` 和 `text` 中查找，再打开命中的 `location` 和相关章节。
3. 以实际页面正文为准，核对其适用系统、版本、架构、网络区域和前置条件；记录使用的页面 URL、章节标题和访问日期。

## 使用规则

- 执行文档中的命令前，先与当前环境核对，不能直接套用其他发行版、架构或版本的示例。
- 涉及环境变更时，遵守项目根 `AGENTS.md` 的授权范围，只修改本轮任务容器或独立环境，不修改共享环境配置。
- 执行后重新运行原失败命令，并检查必要的版本、软件源或连通性，确认文档方法是否解决当前问题。
- 帮助站无法访问、没有覆盖当前环境或说明与实测不符时，记录具体缺口，继续不依赖该信息的分析，不猜测网页内容。

官方文档用于确认环境准备方法和工具用法。根因结论仍须依据原问题复现、运行日志、版本身份和对照实验。
