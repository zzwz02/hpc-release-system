# OpenMM MACA 适配与优化

将此 skill 用于 OpenMM 专属 MACA 工作。通用 HPC MACA 指南保存在 `$hpc-opt-skill` 中；OpenMM 源码布局、编译选择、验证用例、基准测试和调优记录保存在此处。

## 任务导航

- OpenMM 移植、Platform 启用、编译、运行时和正确性任务，阅读 [references/adaptation.md](references/adaptation.md)。
- OpenMM 性能剖析、基准设计、热点分析和性能调优任务，阅读 [references/optimization.md](references/optimization.md)。
